# Credit Policy Lab（信贷审批策略实验室）

**在固定通过率下，哪种筛选策略的坏账率最低——以及收紧审批，代价由多少本会按时还款的客户承担？**

这是一个**策略研究项目，不是违约预测项目**。模型只是中间环节，真正的交付物是
风控团队用来定阈值的那条取舍曲线，以及一份关于"这个阈值能用多久"的诚实说明。

数据用 LendingClub 2007–2018 年公开放贷数据。所有结论都来自一个**只被使用一次**
的跨时间测试集。

---

## 这个项目回答三个问题

**一、通过率该定在哪？**
放松就增长快但损失大，收紧就安全但没量。这是经营决策不是建模问题，模型的作用
是把取舍曲线画出来，让业务在上面挑点。

**二、分数怎么变成策略？**
一个概率值不能直接执行，必须变成"多少分以上通过、多少分以下拒绝、中间进人工
审核"。定这几条边界、以及判断要不要分客群分别定，才是真正的工作内容。

**三、策略什么时候会失效？**
客群会漂移，上线时排序良好的模型，六个季度后未必还行。这个项目用十一年的放款
批次把衰减过程量化出来，并指出该用哪个指标触发重训。

## 流水线做了什么

| 模块 | 产出 |
|---|---|
| `00_data_audit` | 字段资格三分、按批次的填充率漂移、泄漏报警 |
| `01_labeling_and_splits` | 三分类标签映射、表现期、跨时间切分、vintage 曲线 |
| `02_scorecard` | WOE 分箱、IV 筛选、逻辑回归评分卡、可审计的分数表 |
| `03_model_comparison` | 简单规则 vs 评分卡 vs 梯度提升树 |
| `04_policy_simulation` | **取舍曲线、平台评级对照组、粗略经济性测算** |
| `05_stability_monitoring` | 分批次 KS 衰减、PSI 漂移、概率校准、重训信号 |
| `06_reject_inference` | 通过与被拒客群的分布差异、敏感性区间 |

### 三个值得先看的设计决定

**未到期贷款是丢弃，不是算成好客户。** 状态仍为 `Current` 的贷款还没有机会违约，
把它映射成 0 等于把未来的违约者塞进好客户里，后面每一个指标都会虚高。详见
`docs/methodology.md`。

**平台自己的评级被排除在特征之外。** `grade`、`sub_grade`、`int_rate` 在放款时
就已知，所以严格说不算泄漏——但它们是 LendingClub 的模型输出，不是申请人属性。
用了就等于在学平台自己的评分卡。它们被留作对照组：**在同样通过率下，这套策略
能不能跑赢平台自己的排序？** 详见 `docs/leakage_fields.md`。

**IV 过高按 bug 处理。** 151 个字段里约三分之一是放款后才产生的，留在特征里 AUC
能到 0.95 以上，但模型根本没法上线。`src/leakage.py` 会标出任何 IV 超过 0.50 的
特征——对 36 个月违约目标来说，这几乎总是漏网的放款后字段，不是什么发现。

## 这个项目**不能**证明什么

直接写出来，因为这些是审阅者最先会问的：

- **没有因果结论。** 它比较的是筛选策略，不能证明拒绝某个申请人、或者提醒客户，
  能够降低违约。
- **样本选择偏差。** 只有放款的贷款才有表现，所以所有模型都是"条件于通过了
  LendingClub 自己的信贷政策"。拒绝推断做了，但**无法验证**——被拒客户永远没有
  反事实结果。`06_` 给的是敏感性区间，不是修正方案。
- **数据里没有衰退期。** 2012–2015 整段是美国经济扩张期，这里的任何结论都没有
  经过压力情景检验。
- **经济性测算只是示意。** 收益模块用名义利率加一个假设的固定回收率，没有资金
  成本、运营成本和催收模型。它只能在同一套假设下给策略排序，不能估算利润。
- **美国市场、仅 36 个月期限。** 不经重新估计，不可迁移到银行自营信贷或其他市场。

## 复现

```bash
pip install -r requirements.txt

# 从 Kaggle 下载 wordsforthewise/lending-club
# 两个 CSV 放进 data/raw/（路径在 config/config.yaml 里配置）

python tests/test_core.py          # 合成数据冒烟测试，不需要原始数据
jupyter lab notebooks/             # 然后按 00 → 06 顺序运行
```

所有时间窗口、阈值和标签映射都在 `config/config.yaml` 里，notebook 里不写死
任何参数。

## 数据来源

LendingClub 公开放贷数据，经由 Kaggle 镜像
[`wordsforthewise/lending-club`](https://www.kaggle.com/datasets/wordsforthewise/lending-club)
获取——约 226 万笔已放款贷款（2007-06 至 2018-12）和约 2,760 万条被拒申请。
LendingClub 在 2018 年后停止了自家公开下载；这份数据是公开历史数据，未经审计。
